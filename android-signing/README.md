# EvoluaFit development signing

This folder contains the fixed **development** signing material used only for sideload/test APKs generated by GitHub Actions.

Why it exists: Android only accepts an APK as an update when the package name and signing certificate match the installed app. GitHub hosted runners previously generated a fresh debug key for each build, so later APKs could not update earlier ones.

The workflow now decodes the same development keystore on every run and also increments `versionCode` from the GitHub Actions run number.

## Important

This is **not** the final production/Play Store signing strategy. The repository is public, so this development key must be considered public test material. Before public distribution, create a private release/upload key and keep it in secure secrets or use Play App Signing.
